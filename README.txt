RAHAT KHAN PORTFOLIO

Files:
- index.html  -> website structure
- style.css   -> all styling/design
- script.js   -> menu, year and small interactions
- picture.jpg -> your profile image

How to use:
1. Keep all four files in the same folder.
2. Open index.html in Chrome.
3. Replace the portfolio placeholder cards with your own project images.
4. Change your email and Fiverr link inside index.html.
5. Change the WhatsApp/phone action inside script.js.

Recommended portfolio project images:
- Logo design
- Flyer design
- Business card
- Social media post
- YouTube thumbnail
- Invoice design
